# 统一渠道外部站点跳转

## 目标

让管理员能够从“使用日志”中任一记录的渠道标识，直接在新标签页打开该渠道当前配置的上游站点。交互、URL 兼容规则和安全属性必须与“模型路由 → 策略”中的渠道链接一致，减少排查调用记录时在多个页面间查找渠道地址的步骤。

## 背景与已确认事实

- default 前端的“使用日志”包含通用日志（`common`）、绘图日志（`drawing`）和任务日志（`task`）三个页面；三者均只在管理员视图展示渠道列。
- “模型路由 → 策略”和“指标”已经展示渠道当前 `base_url`：合法地址渲染为新标签页链接，无地址或无法识别的地址保持普通文本。
- 通用日志管理员接口已返回 `channel_name`，但三个日志接口均不返回渠道的 `base_url`；自助日志接口刻意隐藏渠道信息。

## 范围

### 纳入

1. `使用日志 / 通用日志` 的渠道单元格及其移动端卡片渲染。
2. `使用日志 / 绘图日志` 的渠道单元格及其移动端卡片渲染。
3. `使用日志 / 任务日志` 的渠道单元格及其移动端卡片渲染。
4. 上述三个**管理员列表接口**为当前页记录补充渠道当前的上游地址，以支持前端跳转。
5. 将模型路由与使用日志使用的 URL 规范化和外链安全规则收敛为同一来源，防止行为继续漂移。

### 不纳入

- 不改变普通用户的自助日志：该视图不展示渠道列，也不得因本需求新增渠道名称或上游地址。
- 不为历史日志保存渠道地址快照；日志打开时使用当前仍存在的渠道配置。
- 不改变渠道管理、模型广场、系统设置等非“使用日志”页面的既有交互。
- 不改变通用日志中的重试链、渠道亲和性提示或“跳转到模型路由指标”的现有动作。

## 功能需求

### FR-1：渠道链接覆盖范围

管理员在三个使用日志页面中看到的每个有效渠道标识均按同一规则处理：

- 通用日志使用记录的 `channel`；绘图和任务日志使用记录的 `channel_id`。
- 表格和移动端卡片必须使用同一单元格渲染逻辑，不能只修复桌面视图。
- 只将该条记录实际展示的渠道设为链接；通用日志的重试链仅保留为提示信息，不将链中每个渠道隐式转换为链接。

### FR-2：与模型路由一致的跳转行为

- 有可用站点地址时，渠道标识可点击，以新标签页打开该地址。
- 链接必须使用 `target="_blank"` 和 `rel="noopener noreferrer"`，不得使用可被弹窗拦截的异步 `window.open`。
- 视觉上保留现有渠道标识（例如 `#123`）及其颜色；可点击状态须具有与模型路由一致的下划线/悬停提示，并可通过键盘聚焦和打开。
- 不改变表格的其他交互，包括渠道亲和性按钮、重试链弹层、复制/详情等已有操作。

### FR-3：地址兼容与降级

链接地址遵循模型路由现有规则：

| 渠道 `base_url` | 目标地址 |
| --- | --- |
| `http://` 或 `https://` 开头 | 原样使用 |
| `//` 开头 | 补为 `https:` |
| 域名（可带端口或路径） | 补为 `https://` |
| 为空、已删除渠道、非 HTTP(S) 协议或无法识别的值 | 不生成链接，保持当前非可点击展示 |

链接只允许 HTTP(S) 目标；不得生成 `javascript:`、`data:`、`file:` 或其他协议的可执行链接。

### FR-4：权限与数据暴露

- `channel_base_url` 仅在管理员读取三个日志列表时返回；自助接口及其他面向最终用户的任务响应不得返回该字段。
- 该字段来自当前渠道配置，仅用于展示跳转；不写入日志表，不需要数据迁移。
- 若渠道已删除或查询失败，列表仍正常返回，受影响记录仅不具备链接。

### FR-5：性能与一致性

- 每个日志列表请求按当前页的去重渠道 ID 批量解析渠道展示信息，禁止逐行查询（N+1）。
- 渠道名称和地址应来自同一次当前配置解析；开启内存缓存时沿用渠道缓存语义，未开启时使用一次批量数据库查询。

## 验收标准

- [ ] 管理员在通用、绘图和任务日志的桌面表格及移动卡片中，点击带有效地址的渠道会在新标签页打开对应上游站点。
- [ ] 交互与模型路由渠道链接一致：HTTPS、协议相对 URL、裸域名均能正确打开；空值、删除渠道、非法协议和无效格式均不能点击。
- [ ] 三个管理员日志接口只新增可选的 `channel_base_url`，不改变现有字段含义、排序、分页或过滤行为。
- [ ] 三个自助日志接口和其他对外任务响应均不返回 `channel_base_url`。
- [ ] 批量列表不存在按记录逐条读取渠道的查询；单页多条同渠道记录不会重复解析该渠道。
- [ ] 通用日志的渠道亲和性、重试链与模型路由预选动作保持可用，且点击链接不会触发无关行级操作。
- [ ] 单元测试覆盖 URL 规范化和降级分支；接口/控制器测试覆盖管理员补充字段、删除渠道降级及自助接口不泄露字段。

## 已作出的产品决策

- 用户补充的“只要这个页面下对应的有渠道的地方，都应该使用这个方式”解释为：使用日志下所有具有渠道列的子页面均纳入，而不是将改动无边界扩展到整个后台。
- 跳转目标为当前渠道配置的上游站点，而不是记录创建时的历史地址；这与模型路由现有行为一致。
